Orbit Launcher 0.8.7 — Rust / Win32

Windows 11 x64向け。orbit-launcher.exeを起動してください。
Rust・Python・Qtの導入は不要です。

反時計回りに円を1.5回描くと表示します。
ほかの円ジェスチャー型ランチャーと同時に有効にすると、両方が反応する場合があります。
Ctrl+Alt+Spaceでも呼び出せます。このキーを登録できなかった場合だけ、代わりにCtrl+Alt+Shift+Spaceを使います。

◇：表示を固定。×／Esc：隠す。完全終了はトレイアイコンのメニューから。
固定していないときは枠の外のクリックを離すと隠れます（全マウスボタン。短いクリックは拾えない場合があります）。
呼び出した画面は最前面に表示し、表示中は最前面を維持します。設定・編集画面はメインより前に表示します。
右上の⋯から表示・ジェスチャーの設定、登録追加、ページの管理ができます。
ボタンの右クリックで編集・ファイルの場所を開く・削除・上下段への移動ができます。
下段の登録は右クリックの「色」で6色を選べます。「なし」で色を解除します。
空きマスへのドラッグは移動、ボタン同士なら入れ替えです。
タイトル・水平線・余白・空きマスからウィンドウをドラッグできます。
行が画面に収まらない場合は、各領域でマウスホイールを使ってください。

exeと同じ場所のdata/config.jsonへ設定を保存します。
書き込み可能な個人用フォルダに置いてください。
他端末へ移す場合、登録パス・フォントの導入状況は端末に合わせてください。
UDEV Gothicは同梱していません。未導入の場合は代替フォントで表示します。

ゴミ箱を空にする際はWindows標準の確認画面が出ます。取り消しても自動再試行しません。
診断ログは明示的に開始した20秒間だけ、マウスの相対座標・経過時間・認識の状態と結果・設定値を保存します。キー入力・画面・絶対座標は保存しません。
インターネット通信・自動更新・自動スタートアップ登録はありません。

複数モニター・画面ごとに異なる拡大率・表示中の拡大率の変更に追従します。
既知の制限：設定画面を開いたまま画面の拡大率を変えると、設定画面の中身が元の大きさのまま崩れます。右上の×（キャンセルと同じで、その回の変更は保存しません）で閉じ、開き直してください。
